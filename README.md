# ecommerce

Repositorio de ejemplo para el proyecto ecommerce.

## Despliegue estático en Vercel

Este proyecto puede desplegarse como una aplicación frontend-only.

- Root: `public`
- Framework: `Other`
- Build command: ninguno
- Output directory: `public`

El inventario y los productos se persisten en `localStorage`, por lo que cada navegador mantiene su propio estado.
